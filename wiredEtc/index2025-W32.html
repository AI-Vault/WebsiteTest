Security researchers at the Black Hat conference revealed a significant vulnerability in OpenAI's Connectors for ChatGPT, allowing the extraction of sensitive data from Google Drive via a "poisoned" document without user interaction. The technique, presented by Michael Bargury and Tamir Ishay Sharbat, involves an indirect prompt injection attack dubbed AgentFlayer. The method utilizes hidden prompts within shared documents to manipulate responses from ChatGPT, ultimately extracting developer secrets like API keys. This highlights the increased security risks associated with integrating AI models with external data sources. Although OpenAI implemented mitigations upon being notified, the incident underscores the potential for abuse as AI's capabilities expand, raising concerns over untrusted data and the protection of sensitive information. link
